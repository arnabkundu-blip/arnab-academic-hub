Refresh model

On page opening, the site attempts a live INSPIRE search and stores an offline cache. The refresh button retries manually. On supported hosted browsers, the records will update on page visits; this static prototype does not execute unattended background jobs. A production service can refresh daily via scheduled server tasks.

Author disambiguation is important: INSPIRE results are filtered for Arnab Kundu, but a verified stable author record should be configured for a production site. Statistics shown here describe returned records only.
